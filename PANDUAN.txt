FITUR
-----
- Absensi harian: Masuk / Tidak Masuk (Alpa, Sakit, Izin).
- Rekap absensi per semester; persentase dihitung dari
  jumlah hari masuk (hari efektif) tiap semester.
- Tahun ajaran = Semester Ganjil + Semester Genap.
  Satu tahun ajaran dapat dilanjutkan ke semester berikutnya.
- Kelas VII, VIII, IX per tahun ajaran, kenaikan kelas otomatis.
- Kelulusan kelas IX + rekapitulasi sekolah lanjutan.
- Data tersimpan sampai 5 tahun; tahun lebih lama diarsipkan
  (fitur Aktif / Nonaktif), tidak dihapus.
- Akun superadmin, admin, dan guru BK. Superadmin dapat membuat,
  mengubah, menonaktifkan, dan menghapus akun admin.
- Foto siswa otomatis dikompres maksimal 100 KB.
- Laporan kerja bulanan sesuai format Oktober 2026, unduh Word/PDF.
  Satu hari bisa berisi banyak kegiatan; tiap kegiatan bisa
  berisi banyak pekerjaan.
- Tema terang & gelap (tombol matahari/bulan di kanan atas).
- Tahun ajaran & semester dapat dihapus (absensi lama tetap tersimpan).
  Bila tombol hapus gagal: buka Tahun & Semester > tombol
  "Periksa Database", lalu jalankan
  supabase\update-hapus-tahun-semester.sql di SQL Editor Supabase.
- Menu navigasi: Dasbor, Absensi, Rekap Absensi, Kelas (tanpa A/B/C),
  Tahun & Semester, Kelulusan, Laporan Kerja, Data Siswa, Akun, Pengaturan.
- Rombel dapat ditambah, diubah, dan dihapus di halaman Kelas.
  Saat rombel dihapus, siswanya dipindah ke rombel lain (data tetap aman).
- Tampilan responsif untuk komputer, tablet, dan HP.
- Data siswa: tambah, edit, import Excel, ekspor Excel.
- Pengaturan identitas madrasah dan penandatangan laporan.


JIKA ADA MASALAH
----------------
- Muncul layar "Hubungkan ke Supabase"
  -> Jalankan supabase\schema.sql di SQL Editor.
  -> Periksa SUPABASE_URL dan SUPABASE_ANON_KEY di config.js.

- "Tabel database belum dibuat" / PGRST205
  -> Skema belum dijalankan. Jalankan supabase\schema.sql.

- Semua menu menampilkan "Halaman belum termuat"
  -> Muat ulang dengan Ctrl + Shift + R (hapus cache).
  -> Bila tetap: jalankan supabase\setup-nama-tabel-salah.sql
     (membetulkan nama tabel yang tertulis "Students", "Profiles", dst).
  -> Buka F12 > Console untuk melihat file/error yang gagal dimuat.

- "Email atau password salah"
  -> Buat/atur ulang akun di Authentication > Users.
  -> Pastikan Auto Confirm User aktif.

- "Akun ini belum memiliki profil guru BK"
  -> Profil belum dibuat. Jalankan ulang bagian trigger/backfill
     pada schema.sql.

- "Akses ditolak"
  -> Pastikan kolom aktif pada tabel profiles bernilai true.

- Lupa password
  -> Authentication > Users > pilih akun > menu > Reset password.

- Ekspor Word/PDF tidak jalan
  -> Pastikan folder vendor\ lengkap dan unduhan diizinkan browser.

- Tampilan berantakan
  -> Gunakan Chrome/Edge terbaru, muat ulang dengan Ctrl + F5.


MENGHAPUS SEMUA DATA (RESET)
----------------------------
Jalankan supabase\reset-semua-data.sql di SQL Editor Supabase.
Menghapus: siswa, absensi, laporan kerja, kelulusan, riwayat
kelas, rombel, semester, tahun ajaran, dan foto siswa.
TIDAK menghapus: akun login dan pengaturan madrasah.
Permanen - buat cadangan lebih dahulu.
