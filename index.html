Hubungkan ke Supabase

Aplikasi ini memakai Supabase (PostgreSQL) sebagai database dan sistem login. Lengkapi konfigurasi berikut satu kali saja.

1

Buat proyek di supabase.com, lalu jalankan supabase/schema.sql di SQL Editor.

2

Buka Project Settings > API, copy Project URL dan anon/publishable key.

3

Tempel kedua nilai tersebut di assets/js/config.js.

4

Buat akun guru BK di Authentication > Users, lalu muat ulang halaman ini.

Panduan lengkap: README.md bagian Supabase. Jangan membuka index.html langsung lewat double-click.
